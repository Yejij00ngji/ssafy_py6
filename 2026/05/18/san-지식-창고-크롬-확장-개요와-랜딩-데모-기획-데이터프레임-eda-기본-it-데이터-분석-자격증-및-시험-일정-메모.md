## pandas로 데이터 기본 점검(EDA) 치트시트
데이터 샘플/크기/타입/통계값/결측/상관관계 등 기본 확인 코드를 정리했다.

```python
# 상위 5개 데이터 확인
df.head()

# 하위 5개 데이터 확인 
df.tail()

# 랜덤하게 데이터 확인
df.sample()

# 원하는 데이터 형태의 데이터만 확인
df.select_dtypes(include = 'data_type')
df.select_dtypes(exclude = 'data_type') 

# 데이터 크기 확인
df.shape

# 데이터 타입 확인 
df.info()

# 수치형 데이터 통계값 확인 
df.describe()

# 범주형 데이터 통계값 확인 
df.describe(include = 'O')

# 결측치 확인하기
df.isnull().sum()

# 상관관계
df.corr()

# 데이터 합치기 (axis의 default값은 0, 즉 가로로 합쳐짐) 
df = pd.concat([[x_train, y_train.컬럼명]],axis=1)
```

## IT/데이터 분야 자격증 분류와 준비 관점 메모
분야별로 자주 언급되는 자격증들을 분류해 메모했다.

- 프로그래밍
  - 국제: OCJP, OCWCD, OCBCD
  - 국가공인: 정보처리 기능사/산업기사/기사
    - 기능사: 자격요건 없음
    - 산업기사: 2년 경력 또는 학력
    - 기사: 4년 경력 또는 학력
- OS(운영체제)
  - 국제: LPIC, MCSE, MCSA
  - 국가공인: 리눅스마스터 1급/2급(자격요건 제한 없음)
- 네트워크
  - 국가공인: 네트워크관리사 2급(자격 제한 없음)
    - 네트워크관리사 1급은 국가공인이 아닌 민간자격증이라는 메모 포함
  - 국제: CCNA(초급) / CCNP(중급) / CCIE(고급)
- 해킹/정보보안
  - 국가공인: 정보보안 산업기사/기사
  - 국제: CISA, CISSP (난이도 높고 5년 자격 제한을 거는 경우가 많다는 메모)
- 데이터 분석
  - 국가공인: ADsP / ADP
- 데이터베이스(DB)
  - 국제: OCA / OCP / OCM
- 클라우드 아키텍처
  - MS Azure, AWS 아키텍처

준비 관점 메모
- 중고등학생은 국제자격증이 실사용처가 적을 수 있으니 **국가공인 중심**으로 고려
- 자격증은 “기술/지식을 갖추고 있다는 증명 + 최소한의 성의”라는 관점
