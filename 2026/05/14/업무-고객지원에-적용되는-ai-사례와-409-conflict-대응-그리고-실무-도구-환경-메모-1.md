## HTTP 409 Conflict: 주요 원인과 해결
- **데이터 중복(가장 흔함)**
  - 원인: 이미 사용 중인 아이디/이메일로 회원가입 시도, 고유 파일명 중복 업로드
  - 해결: 다른 아이디/파일명으로 재시도
- **버전 제어 충돌(Version Control Conflict)**
  - 원인: 서버의 최신 버전보다 오래된 파일을 덮어쓰기(PUT) 시도
  - 해결: 서버 최신 데이터 가져온 뒤 수정 사항 반영해 재업로드
- **서버 상태 및 구성 충돌**
  - 원인: 로드 밸런서 구성 변경, 이전 작업 미완료 상태에서 새 요청 유입
  - 해결: 잠시 후 재시도 또는 충돌하는 이전 작업 취소
- **네트워크/환경 문제**
  - 원인: 공용 와이파이에서 프록시 서버 간 데이터 충돌 가능
  - 해결: 다른 네트워크로 전환, 브라우저 캐시/쿠키 삭제
